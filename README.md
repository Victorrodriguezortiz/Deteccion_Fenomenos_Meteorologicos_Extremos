# Deteccion_Fenomenos_Meteorologicos_Extremos
Código desarrollado para la detección y análisis de fenómenos meteorológicos extremos en España, integrando datos de reanálisis, satélite y calidad del aire. El repositorio incluye los pipelines de extracción, limpieza, preparación de datasets, modelado predictivo, explicabilidad y visualización empleados en el trabajo.
